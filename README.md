# Recedit

Offline native video editor for Linux, written in Rust.

**[Download Recedit Beta 1 — Patch 1](https://github.com/sayedrisat/recedit/releases/tag/v1.0.0-beta.1.1)**

Ubuntu 26.04 amd64. Manual editing works offline after runtime dependencies are installed. The release includes the `.deb` installer, SHA-256 checksum and installation/feature/qualification notes.

This repository distributes binaries and documentation. Application source and local source snapshots are private.

Report reproducible problems in [Issues](https://github.com/sayedrisat/recedit/issues). Include version, Ubuntu/GPU/backend, source codec/FPS and reproduction steps; review diagnostics before sharing. Media/projects are optional and are never uploaded automatically.

Beta 1 is the functional core editing release. The complete Home Dashboard, major visual redesign and Agent Mode are planned for later milestones. See the release notes for supported profiles and known limits.
